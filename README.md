# Cloud Kitchen Analytics Platform

An end-to-end business intelligence platform for cloud kitchens.

## Technology Stack

- HTML
- CSS
- JavaScript
- Flask
- Python
- PostgreSQL
- SQLAlchemy
- Pandas
- NumPy
- Matplotlib
- Plotly
- Power BI
- Machine Learning

## Main Features

- Sales Analytics
- Revenue Analytics
- Product Analytics
- Customer Analytics
- RFM Segmentation
- Delivery Analytics
- Food Cost Analysis
- Branch Comparison
- AI Recommendations
- Demand Forecasting
